$$\text{Weighted Variance} = \left(\frac{N_{\text{left}}}{N_{\text{total}}}\right) \text{Var}_{\text{left}} + \left(\frac{N_{\text{right}}}{N_{\text{total}}}\right) \text{Var}_{\text{right}}$$
using these two formulas we will calculate the overall weighted average variance for that split. select the column and value for the minimum value.
