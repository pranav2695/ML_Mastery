## CART
It is the backend algorithm which is used in the decision trees. we also have different alogs like Id3, c4.7, major difference is impurity function and CART use binary tree only.  
for every node first we need to find the column and value on which we are going to do the split, this is selected based on the minimum value of ginny impurity.   
$Gini-impurity = 1 - \sum_{i=1}^{k}p_k^2$   
P_k is the probabilty of each target class in the sub space of data, field = science , then again we calculate the gini impurity for field != science , then again we will calcualte probability of employed and unemployed in that sample space. then we use above formula to calculate the gini impurity and then we calculate the overall G value. 

$G(Q_m, \theta) = \frac{n_m^{left}}{n_m} H(Q_m^{left}(\theta)) + \frac{n_m^{right}}{n_m} H(Q_m^{right}(\theta))$   
Note: if we will have the more than 2 class in the column then we need to calculate the G value for all the classes.   
Take the column one value and now calculate the target column values to calculate the gini impurity then calculate the weightage average and that will be your G value. Now we will compare this G value first internally with all the possible G value then we will compare it between the other column values.

## Understanding the ginni impurity   
The gini impurity is a measure of how often a randomly chosen element from the set would be incorrect labelled if it was randomly labelled according to the distribution of labels in the subset.  
1>gini impurity > 0 (more it is close to 0 more it is preferred) 
## Advantages and Disadvantages 
- simple to understand and to interpret, Trees can be visualized.
- Required little data preparation. Other techniques often require data normalization 
- The cost of using the tree is logarithmic in the number of data points. 
- Able to handle the both numerical and categorical data. 
- Can work on non linear datasets
- can give you feature importance
### Disadvantages 
- Decision trees learners can create the over complicate trees which will not able to genearlize the data well. 
this is called overfitting. Mechanisms such as pruning, setting the minimum depth of the tree are necessary to avoid this problem.
- DT can be unstable because small variations in the data might result in a completely different tree being generated. this problem is mitigated by using ensemble model.
