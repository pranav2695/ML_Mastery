## Core idea 
This can be understand with the prediction stage, in the ensemble technique we have collections of different models (they can be different by giving the different data or different algos).  
for the classification problem result of the ensemble models will be the majority count   
for the regression problems result of the ensemble models will be the mean of output values of the all the models.   
## Types of Ensemble Learning 

1. Voting : Base models are different algos, for eg svm, dt, rf. data giving to all the models is same. 
2. Bagging : Stands for Bootstrap aggregration, base model is same but we give different data to each base models for eg  Random forest. In bootstrapping we randomly select the sample data set and give that to models then we put back that data and again do the same thing to different base model. Now every base model will have different dataset to train on. Only DT bagging is called the random forecast but for other base models it will called bagging only. 
3. Boosting : Base model is same but data we give to first base model, then it will give info of incorrect prediction and so on. it works in series for eg. adaboosting, gradient boosting, xg boost
4. Stacking : It is the enhancement of votting so in stacking output of base models is giving as the input to one more model and target value is the correct value. with the help of this we assign weights to each base model. Basically to give more weightage to model who is more correct compared to others.
