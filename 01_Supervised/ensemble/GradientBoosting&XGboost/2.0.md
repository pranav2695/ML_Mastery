## Gradient boosting 
In the boosting we use the concept of the additive modelling where we create the composite function by adding the two functions for eg x + sinx, same thing is used by the gradient boosting. 
It is particulary effecitve when the data has complex, non linear relationships, and it often performs well even  with little hyper parameter tuning. 
## How Gradient boosting works 
- we need to find the mathmetical relationship between y = f(x), then apply the additive modelling concept.   
$f_0(x) + f_1(x) + f_2(x)  .... $
- Need differential function of y_hat, y_i. we will use the MSE.  
- first model is the mean of the y_i. 
- Now we keep on giving the error of model to next model, which is called the pseudo residuals. training data will be same but target is pseudo residuals. 
- we also have the learning rate n (shirnkage factor) we scales down the contribution of each newly added tree.
## Difference between the gradient boosting and Xgboost algo
Xb boost is the highly scalable, optimized and regularized implementation of the gradient Boosting machine algorithm
- we have built in regularization on leaf weights
- can handle the missing values as well. 
- Highly optimized
## Difference in XGboost and Lighgbm
- In XGboost we have tree level growth and in lightgbm we have leaf wise growth 
- Exact pre sorting for split finding in XGboost and Histogram based for lightgbm
- Xg boost moderate to fast and lightgbm is ultra fast. 
- xb boost required pre processed catergorical feature to one hot encoding and all whereas lighgbn can handle catergorical features as well.
