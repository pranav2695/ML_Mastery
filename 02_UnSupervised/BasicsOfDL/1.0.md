## Random variable 
A random variable is the function which maps the result of random experiment to the numerical value. it takes values based on probability Mass function or Probability density function
1. Discrete Random variable: Takes values based on the Probability mass function 
2. Continous Radom variable: Takes values based on the Probability density function
## Fundamental probability Distribution 
### Bernoulli Disrtribution
it models the sigle binary trail, where we have only two outputs 1 as success and 0 failure with probabilty 1-p 
$$\text{PMF: } P(X = x) = p^x (1 - p)^{1 - x} \quad \text{for } x \in \{0, 1\}$$
Parameters: $p \in [0, 1]$  
Expectation: $\mathbb{E}[X] = p$  
Variance: $\text{Var}(X) = p(1 - p)$  
Deep Learning Application: Used for binary classification tasks. The final layer of a binary classifier uses a Sigmoid activation function to output $p = P(Y=1 \mid X)$. Minimizing the negative log-likelihood of a Bernoulli distribution yields the Binary Cross-Entropy (BCE) Loss.
## Gaussian Distribution(Normal distribution)  
$$\text{PDF: } f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left( -\frac{(x - \mu)^2}{2\sigma^2} \right)$$
Parameters: Mean $\mu \in \mathbb{R}$ (location), Variance $\sigma^2 > 0$ (spread)Standard Normal: $\mathcal{N}(0, 1)$ with $\mu = 0$ and $\sigma^2 = 1$  
Deep Learning Applications of Gaussian Distributions:  
1. Loss Functions: Minimizing Mean Squared Error (MSE) loss is mathematically equivalent to Maximum Likelihood Estimation (MLE) under the assumption that target noise follows a Gaussian distribution.  
2. Weight Initialization: Schemes like He and Xavier initialization draw initial network weights from Gaussian distributions centered at zero with variances tuned to keep activations stable across layers.  
3. Generative Modeling: Variational Autoencoders (VAEs) enforce a standard Gaussian prior $\mathcal{N}(\mathbf{0}, \mathbf{I})$ on the latent space to allow continuous sampling.

## Law of Large numbers 
If you perform an experiment independently many times, the average of your sample results will get closer and closer to the true expected value as the number of trials grows.  
$$\bar{X}_n = \frac{1}{n} \sum_{i=1}^{n} X_i$$
